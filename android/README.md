# AsterHand Android 1.0 / build 82

本版无需序列号，不再进行应用授权联网验证或定时复核。已移除激活页、授权后台任务及 AI / 工具 / 终端 / 语音 / 远控的序列号限制。AI 服务连接和设备原有的配对、执行权限照常管理。

首次打开新版会显示五步入门引导，可跳过；完成或跳过后不再自动显示。在“设置 → 使用指南”可以离线查阅十个功能主题或重新播放。说明文字支持五种界面语言，截图使用小米 11 的英文实机页面；点击“查看大图”可展开。引导翻页不申请系统权限，也不启动语音或登录。

这是沿用 `com.pocketagent` 应用标识、原图标、项目格式与加密存储的覆盖升级版。请直接安装 APK，不要先卸载旧应用。当前发布物为开发签名 APK，开启了仅用于本应用页面的开发诊断；正式公开发行前应另做生产签名及关闭调试的构建。

## 安装与权限

最低构建目标为 Android 6 / API 23，当前真机包括小米 11 M2011K2C / Android 17 自定义系统，以及 23116PN5BC / shennong / Android 16。最低构建版本不等于所有旧系统、WebView 和厂商系统均已实测。

1. 安装 `dist/AsterHand-1.0-Android.apk`，打开 AsterHand。
2. 在设置中选择 AI 服务商，填写自己的 API Key，或者由用户在手机浏览器完成 ChatGPT 登录。项目、文件和密钥保存在手机；不会从电脑或其他手机迁移账户。
3. 如需悬浮窗、屏幕控制或通知，分别进入相应系统授权页面。开启屏幕助手不会替代本应用的“AI 屏幕控制”“远程屏幕操作”开关。
4. 在“执行权限”选择普通用户、ADB 或 Root；每档先验证实际执行身份，失败时保留原档位。

| 等级 | 执行身份与用途 | 启用条件 |
| --- | --- | --- |
| 普通用户 | 应用自己的 UID；项目文件、应用可访问的命令和文件 | 安装即可使用；其他 App 的私有目录仍受系统限制 |
| ADB | UID 2000 / shell；ADB 能访问的命令、截图与输入 | 已授权的 USB ADB 会话运行下方激活脚本，不需要 Root |
| Root | UID 0；Root 管理器授权范围内的本机操作 | 给 AsterHand 单独授权 Root，系统中有可用的 `su` |

新的部分 Root 管理器使用预授权列表，不会在首次执行时自动弹出授权。如果提示找不到 `su`，请在 Root 管理器给 **AsterHand** 授权，再重新打开应用；不要为了本应用关闭系统安全策略。

在已配置 Python 和 ADB 的电脑中运行：

```powershell
adb devices -l
python scripts/android_adb_bridge.py --serial 设备序列号
```

这会从已授权的 shell 启动本应用专用的 UID 2000 服务，使用带随机密钥的本机回环认证通道。激活凭据不打印、不放入命令行参数，也不使用 Root 或 `run-as`。APK 覆盖升级或手机重启后可重新运行激活脚本。停止服务：

```powershell
python scripts/android_adb_bridge.py --serial 设备序列号 --stop
```

执行等级决定工具初始身份，并不是可以阻止恶意代码提权的容器。手动终端仍是实际系统 shell；不要把普通用户档位视为对任意代码的安全隔离。

## 页面与任务

- 首页包含项目、对话、模型与思考深度、聊天和工具进度。新回复自动跟随；手动上翻后暂停跟随，点到底部恢复。
- 项目和对话支持创建、重命名、多选、全选和批量删除。删除项目默认保留文件，可以额外选择删除该项目的独立目录。
- 运行中的任务只接受同一项目、同一对话的追加消息；切到其他对话时会拒绝追加并保留草稿。发送时记录页面来源，延迟返回的成功回执也不会清空另一段对话的新草稿。
- 新安装的默认项目使用独立目录。旧默认项目的文件位置保留，文件接口会排除其他已登记项目的目录并过滤列表入口；显式 shell / 终端仍按所选权限执行。
- 支持系统文件选择器导入文件和图片，每条消息最多 4 项、每项最多 8 MiB。不同服务商支持的附件类型不同，不支持时会明确报错。
- AI 连接可选择通用 API 或 ChatGPT 登录；可填写 HTTPS API 地址、模型 ID 和推理深度。自定义地址使用 OpenAI 兼容 Chat Completions；旧密钥不会被自动删除。模型、附件、工具与推理档位取决于服务商，不承诺提高套餐额度或速度。
- 工具需要批准时显示具体操作。Root / ADB 升级申请独立于自动允许，提供拒绝、允许一次和始终允许。停止任务取消后续请求，不回滚已经执行的操作。
- 连续语音使用 Android 语音识别和朗读引擎，麦克风与朗读分别静音。识别引擎是否联网由设备服务决定；首次使用需允许麦克风。
- 语音无回应自动结束默认 5 秒，可选 5 / 10 / 15 秒和自定义 1–3600 秒；仅等待人说话时计时，AI 等待与朗读暂停。静音但无人输入仍会计时。状态胶囊显示真实聆听阶段与轻微圆点动画，不模拟音量。

## 双向控制与终端

远程连接支持搜索局域网、配对码和 IP 申请。设备身份绑定公钥，不以 IP 作为信任依据。接收端可允许一次、始终允许或拒绝，之后可在设置修改。允许一次随控制会话结束撤销；异常断开仅保留有限重连时间。

与 Windows / iOS 使用同一套配对和加密 RPC 协议，包含屏幕截图、点击、滑动、输入、文件和终端接口。远程屏幕和本地 AI 屏幕开关独立。接收端始终使用自己选择的执行等级，控制端不能凭连接权限替接收端打开 Root。

本地和远程终端保留工作目录、变量与连续输出，按所有者隔离会话。当前是持续 shell 会话，不是完整的交互式 PTY，部分全屏终端程序不适用。Android 不自带 iOS 的 Theos / SDK 或桌面构建工具链；AI 创建源代码不代表手机已能构建对应平台软件。

## 屏幕、悬浮窗与后台

普通用户档位使用已启用的无障碍服务：手势需要 Android 7 / API 24，截图需要 Android 11 / API 30。ADB 和 Root 使用设备实际提供的截图及输入命令；Unicode 输入优先走已授权的无障碍文本接口，失败会报告原因。

悬浮窗提供任务状态、停止 / 继续、主动发消息、问题回答、语音及独立静音。状态胶囊可拖动、隐藏或锁在顶部；最终回复展示 3 秒后隐藏。AI 截图和点击期间临时隐藏交互浮层，结束后恢复。灯效有独立开关、宽度和不透明度设置；装饰层不接收触摸。

打开后台常驻后，前台服务承担远控和新申请；AI 任务有独立运行服务。具备悬浮窗权限时，后台连接申请显示三选项卡片，否则使用通知。Android 的强行停止、重启、厂商省电限制仍可能终止服务，不能保证进程永不退出。重启只恢复用户允许的服务，不重放结果未知的 AI 操作或自动打开麦克风。

当前远程画面使用限流和背压的 JPEG 采集，尚未提供硬件编码视频传输；实际流畅度受截图接口、设备和网络影响。

“设置 → 重启所有服务”停止当前任务、语音及终端，恢复用户原先开启的远控和悬浮服务，并核对运行状态。身份、密钥、项目、权限档位与配对保留；不会自动重试任务。ADB 是独立的、此前由电脑授权的 shell 服务，重启 App 服务保留它的授权；若 ADB 服务本身已退出，仍需在已授权电脑重新运行激活脚本。

App 内不再提供关闭触感的选项，四档样式与 iOS 对齐；旧关闭值恢复为默认反馈。实际触感受设备马达与系统策略影响。

覆盖升级使用同签名 `install -r`，保留现有项目、登录与授权。已验证的小米 11 定制系统在系统“强行停止”应用后会移除 AsterHand 无障碍授权；需要用户在系统页面重新允许。不要为了升级强行停止应用，也不会静默重写系统授权。部分厂商另行限制 ADB 输入注入：即使命令身份已确认为 UID 2000，也不代表该 ROM 允许 ADB 点击；受限时会报告实际错误。

## 构建与验证

本地构建使用 JDK 17、Android SDK platform 35 / build-tools 35、Python，以及项目保留的开发签名：

```powershell
python -X utf8 scripts/build_android.py
python -X utf8 scripts/build_android_tests.py
python -X utf8 scripts/check_android_ai.py
node scripts/check_android_ui.mjs
```

后两项主要是离线 fixture 和页面测试。真机安装、真实 UID、远程双向协议及 UI 结果另记于根目录 `TESTING.md`；尚未完成用户账户登录、真实模型和两轮语音验收时，不把离线通过写成相应功能已真机通过。
