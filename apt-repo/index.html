OPENSSH / UPDATES

Dependencies included. Updates tracked.

Package provenance & versions ↗

Environment-specific sources include original OpenSSH packages and their runtime dependencies. A scheduled workflow checks stable AsterHand GitHub Releases and the native upstream repositories every 6 hours.

Rootful packages use Bingner / Elucubratus. Procursus rootful users should keep their bootstrap's OpenSSH and use the unified AsterHand-only source.

Refresh your package manager and approve an upgrade to update your device. Adding a source alone installs nothing. Installing OpenSSH may start its SSH service; configure your credentials or SSH keys.
