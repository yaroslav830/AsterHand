# AsterHand · Android

English · [简体中文](android.zh-CN.md)

A local AI agent and encrypted cross-device control for Android, with receiver-selected Standard, ADB and Root execution.

## Version

Display version **1.0**, source build **82**. Preview software; platform capabilities and tested configurations vary.

## Install and use

Android 6.0 / API 23 is the build target. Root requires the device owner to grant access through its Root manager; ADB requires an authorized bridge. See [Android documentation](../../android/README.md).

[Project homepage](https://github.com/yaroslav830/AsterHand) · [Downloads and release notes](https://github.com/yaroslav830/AsterHand/releases)

## Cross-device Root support

Control only devices you own or are authorized to administer. Pairing, Root/ADB, accessibility, screen recording and microphone access remain under the receiving device owner’s control. Pairing does not grant Root or bypass operating-system permissions.
