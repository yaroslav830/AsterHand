# AsterHand · Linux

English · [简体中文](linux.zh-CN.md)

The Linux desktop client and local agent, with encrypted control of paired devices and MCP integration.

## Version

Display version **0.1.0**, source build **82**. Preview software; platform capabilities and tested configurations vary.

## Install and use

A compatible graphical Debian/Ubuntu desktop is required. X11 input control and Wayland limitations are documented in [Linux instructions](../../desktop/linux/README.md).

[Project homepage](https://github.com/yaroslav830/AsterHand) · [Downloads and release notes](https://github.com/yaroslav830/AsterHand/releases)

## Cross-device Root support

Control only devices you own or are authorized to administer. Pairing, Root/ADB, accessibility, screen recording and microphone access remain under the receiving device owner’s control. Pairing does not grant Root or bypass operating-system permissions.
