A FEW THINGS TO KNOW

Before you connect.

Does AsterHand root or jailbreak my device?

No. It uses Root, ADB, jailbreak helpers and screen capabilities that you have already enabled and authorized. AsterHand does not perform a jailbreak or grant those permissions by pairing.

Does “local agent” include an offline AI model?

The agent executes tools on your device. Model inference comes from the AI service you select; an offline model is not bundled. Messages, attachments and tool results needed for inference are sent to that selected service.

Which iOS build should I install?

Check dpkg --print-architecture in an existing device terminal. iphoneos-arm matches Rootful, iphoneos-arm64 matches Rootless, and iphoneos-arm64e matches RootHide. The current AsterHand targets are iOS 14+ for Rootful and iOS 15+ for Rootless/RootHide; target compatibility is not a guarantee for every jailbreak.
