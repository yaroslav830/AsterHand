03 / INSTALLATION GUIDES

Install AsterHand

Find downloads, system requirements and installation steps for your device.

Windows

0.1 testing · Windows 7 SP1 or later · .NET Framework 4.6.2 or later

  1. Run AsterHand-Windows-Setup.exe to install for your user account. For the portable version, save AsterHand-Windows.exe in a folder and run it there.
  2. Open AsterHand. Configure your AI connection in Settings, then use Remote connections to discover or pair a receiver.
Download installer Download portable EXE

macOS

0.1.4 preview · Intel: macOS 10.15+ · Apple silicon: macOS 11+

  1. Choose the ZIP for your Mac’s processor, unzip it, then move AsterHand.app to Applications and open it.
  2. The preview uses ad hoc signing. If macOS asks you to review the app, open System Settings → Privacy & Security. For screen viewing and control, grant Screen Recording and Accessibility as needed. A new build may require these grants again.
Download Intel ZIP Download Apple silicon ZIP

Linux

0.1.0 preview · Graphical Debian/Ubuntu desktop · amd64 or arm64

  1. Run uname -m to check your processor. Use amd64 for x86_64 and arm64 for aarch64.
  2. Install the DEB using your package manager, or run the command below from the download directory. Open the GUI as your regular user.
  3. X11 local input uses xdotool. Wayland currently lacks local input injection, and screen capture may show a system sharing prompt. A paired phone uses its own input permissions.
Download amd64 DEB Download arm64 DEB 
sudo apt install ./AsterHand-0.1.0-linux-amd64.deb
asterhand

For arm64, use AsterHand-0.1.0-linux-arm64.deb in the first command.

Android

1.0 preview · Android 6.0 minimum build target · Development-signed APK

  1. Download AsterHand-1.0-Android.apk, then open it with the Android package installer.
  2. Choose Standard, ADB or Root in AsterHand. Standard mode needs applicable screen and accessibility permissions. ADB needs authorized debugging. For Root mode, approve the request in your device’s existing Root manager.
Download APK

iOS

1.0 preview · Compatible jailbreak required · Rootful iOS 14+ · Rootless and RootHide iOS 15+

  1. For manual installation, choose the DEB for your active jailbreak environment. Open it in the package manager and review the installation queue. The packages declare an OpenSSH dependency.
  2. Open AsterHand, connect your AI service and enable the screen and Root permissions you intend to use.
Download Rootful DEB Download Rootless DEB Download RootHide DEB

Set up AsterHand MCP

  1. Keep the AsterHand control center open on Windows, macOS or Linux. Pair any Android or iOS receivers you plan to use.
  2. Install Node.js 20+, Python 3.11+, pnpm and the Codex CLI. Open a terminal at the root of the AsterHand repository and run the command below.
  3. Open a new Codex conversation after the installer registers asterhand. Ask it to call devices_list, select the exact paired device, and inspect its screen before sending input. Check the result on the device.
python scripts/install_asterhand_mcp.py

MCP uses the desktop app’s local connection and existing device pairings. Root, ADB and screen tools still require the receiver’s permission.

A FEW THINGS TO KNOW

Before you connect.

Does AsterHand root or jailbreak my device?

No. It uses Root, ADB, jailbreak helpers and screen capabilities that you have already enabled and authorized. AsterHand does not perform a jailbreak or grant those permissions by pairing.

Does “local agent” include an offline AI model?

The agent executes tools on your device. Model inference comes from the AI service you select; an offline model is not bundled. Messages, attachments and tool results needed for inference are sent to that selected service.

Which iOS build should I install?

Check dpkg --print-architecture in an existing device terminal. iphoneos-arm matches Rootful, iphoneos-arm64 matches Rootless, and iphoneos-arm64e matches RootHide. The current AsterHand targets are iOS 14+ for Rootful and iOS 15+ for Rootless/RootHide; target compatibility is not a guarantee for every jailbreak.

See the iOS installation guide
Where are the source and release files?

Source and platform documentation are on GitHub. Available client installers are in the main project's Releases. Original AsterHand code has no open-source license grant; third-party notices and licenses remain in effect.
