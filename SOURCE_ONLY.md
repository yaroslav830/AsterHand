# Source branches and release assets

[English](SOURCE_ONLY.md) · [简体中文](SOURCE_ONLY.zh-CN.md)

Source branches contain related source, necessary assets, build configuration and checks. Credentials, pairing records, signing keys, logs, dependency caches and compiled installers are excluded from the source tree.

The AsterHand source repository is public. Client installers for the five platforms are distributed separately through [AsterHand Releases](https://github.com/yaroslav830/AsterHand/releases). Existing third-party licenses are retained. Public visibility does not grant a new open-source license to the original code.



## Official website assets

`website/` contains the public website source and four existing sanitized EN/ZH product videos used by the website. `docs/images` contains the existing public app screenshots. These are presentation assets; installers and private runtime data remain excluded. GitHub Pages publishes only the generated website directory.
